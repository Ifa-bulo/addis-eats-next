# Addis Eats project update: 12 October 2026

This update addresses four items requested for the deployed Addis Eats app.

## Changes made

1. **Social previews:** Added `src/lib/site-url.js` to choose a safe canonical origin. Production falls back to `https://addis-eats-next-omega.vercel.app` rather than `localhost` if the Vercel environment variable is absent or accidentally set to an HTTP URL. Root and homepage metadata, robots, sitemap, and structured data now use this origin. The existing `public/og-image.jpg` is already 1200 × 630 and about 112 KB, so it is reused.
2. **Mobile hero:** Added a mobile-specific dark image overlay and moved the hero copy to the top. The mobile heading and paragraph no longer wait below a fixed 218 px image gap.
3. **Cart confirmation:** The shared cart provider now displays an accessible confirmation toast after any add-to-cart action, with the dish name and a View cart link. It dismisses automatically and can be closed manually.
4. **Delivery choices:** Checkout now has its own Delivery Options card, an Addis Ababa area dropdown, and Standard / Express delivery choices. Delivery fees are calculated and validated server-side and stored with the order. Order tracking displays the selected delivery option and fee.

## Deploy to Vercel

1. Copy the updated files into the matching paths in your local repository. Do not replace your `.env.local` with a shared or example file.
2. In Vercel, open **Project → Settings → Environment Variables** and set `NEXT_PUBLIC_SITE_URL` for Production to:

   `https://addis-eats-next-omega.vercel.app`

   If you use a custom domain, use that public HTTPS origin instead. Do not put `http://localhost:3000` into Vercel's Production environment.
3. Commit and push the changes, or trigger a deployment from your connected GitHub repository.
4. Confirm that this image loads in a private browser window:

   `https://addis-eats-next-omega.vercel.app/og-image.jpg`

5. View the deployed page source and search for `og:image`. Its value should begin with the deployed HTTPS origin, not `localhost`.
6. Check `https://addis-eats-next-omega.vercel.app/robots.txt` and `https://addis-eats-next-omega.vercel.app/sitemap.xml` for production URLs.

Social platforms cache previews. After the metadata is corrected, test the link with a fresh share URL or ask the platform to re-fetch the page if it continues showing an older card.

The area list and standard / express rates are demo values for this project, not verified logistics-provider quotes. Adjust `src/lib/delivery.js` to match actual operating areas, fees, and estimates before accepting real customer orders.
